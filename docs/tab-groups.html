📁 Tab Groups

Chrome 原生标签组功能

创建分组

  1. 选中一个或多个标签
  2. 右键选择 "Create Group"
  3. 在弹出的输入框中输入分组名称
  4. 系统自动分配随机颜色

添加到已有分组

  1. 选中一个或多个标签
  2. 右键选择 "Move to..." → 选择窗口 → 选择分组
  3. 或直接拖拽标签到分组区域

分组显示

  • 分组以缩进 + 左侧彩色边框显示
  • 点击分组标题可折叠/展开
  • 显示分组内标签数量

分组颜色

支持 Chrome 原生的 9 种颜色：

grey
blue
red
yellow
green
pink
purple

orange

分组操作

操作方式
折叠/展开点击分组标题
折叠所有分组点击工具栏折叠按钮
解散分组右键 → Ungroup（标签保留）
关闭分组右键 → Close Group（关闭所有标签）
移动整个分组右键 → Move to... → 窗口名
合并到其他分组右键 → Move to... → 窗口 → 分组名
移出标签右键标签 → Remove from Group
