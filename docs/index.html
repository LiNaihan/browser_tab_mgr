Smart Tab Cleaner 产品说明书

📌 什么是 Smart Tab Cleaner？

Smart Tab Cleaner 是一个 Chrome 侧边栏扩展，用于管理浏览器标签页。支持多窗口管理、多选操作、Tab Groups 等功能。

🪟

多窗口管理

统一管理所有浏览器窗口的标签

📁

Tab Groups

支持 Chrome 原生标签组功能

🔄

会话保存

保存和恢复浏览状态

🎯

拖拽操作

标签、分组、窗口均可拖拽

⚠️ 已知限制

  • 无法隐藏原生标签栏：Chrome 不允许扩展控制浏览器 UI
  • 无法检测主窗口点击：Side Panel 是独立上下文，`window.blur` 不触发
  • 无法修改窗口标题：Chrome 没有 `chrome.windows.setTitle()` API
