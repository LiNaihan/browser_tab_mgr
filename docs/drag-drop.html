🎯 拖拽操作

标签、分组、窗口的拖拽逻辑详解

概述

拖拽操作与右键菜单 "Move to..." 实现相同的功能，提供更直观的交互方式。三种实体（Tab、Group、Window）各有不同的拖拽行为。

1. 标签（Tab）拖拽

拖放目标 效果 等效右键操作
另一个标签上 插入到该标签位置 —
分组标题（Group Header） 加入该分组 Move to → 分组名
分组区域（Group Body） 加入该分组 Move to → 分组名
窗口标题栏 移动到该窗口开头（不分组） Move to → 窗口名
窗口区域 移动到该窗口末尾（不分组） Move to → 窗口名
💡 视觉反馈
  • 拖拽时，目标标签显示 drag-over 高亮
  • 跨窗口时，目标窗口显示 window-drop-target 高亮
  • 拖到分组时，显示 group-drop-target 高亮

2. 分组（Group）拖拽

拖拽分组标题栏可移动整个分组。

拖放目标 效果 等效右键操作
另一个分组 排序：移动到目标分组位置（保持分组属性） —
窗口标题栏 移动：整个分组移动到该窗口（保持分组属性） Move to → 窗口名
窗口区域 移动：整个分组移动到该窗口（保持分组属性） Move to → 窗口名
💡 分组移动

无论拖到哪里，分组的 title 和 color 都会保持。跨窗口移动时会在新窗口重建相同属性的分组。

3. 窗口（Window）拖拽

窗口拖拽仅用于排序，通过标题栏左侧的 ⋮⋮ 手柄触发。

拖拽行为

操作 效果
拖拽手柄 ⋮⋮ 开始窗口排序拖拽
拖到另一个窗口上方 插入到该窗口之前
松开 保存新顺序到 chrome.storage.local

折叠行为

时机 行为
开始拖拽时 自动折叠所有窗口，便于看清窗口位置
松开时 恢复拖拽前未折叠的窗口（已折叠的保持折叠）
💡 实现细节

开始拖拽时，记录当前未折叠的窗口到 windowsExpandedBeforeDrag，结束时只展开这些窗口。

视觉样式

CSS 类

类名 应用对象 效果
.dragging 被拖拽的标签 半透明
.group-dragging 被拖拽的分组 半透明、虚线边框
.window-dragging 被拖拽的窗口 半透明、虚线边框
.drag-over 目标标签 高亮背景
.group-drop-target 目标分组 蓝色高亮边框
.window-drop-target 目标窗口 蓝色高亮边框
.window-drag-over 窗口排序目标 发光边框

状态变量

let draggedTab = null;              // 拖拽中的标签 { id, windowId }
let draggedGroup = null;            // 拖拽中的分组 { id, windowId }
let draggedWindow = null;           // 拖拽中的窗口 ID
let windowsExpandedBeforeDrag = new Set();  // 拖拽前展开的窗口

统一 Move 操作模块 (MoveOperations)

拖拽操作

函数操作说明
tabsToGroup(tabIds, groupId) Tab(s) → Group 将标签加入已有分组
tabsToWindow(tabIds, windowId) Tab(s) → Window 移动到窗口（不分组）
groupToGroup(sourceGroupId, targetGroupId) Group → Group 排序（移动到目标位置，保持属性）
groupToWindow(sourceGroupId, windowId) Group → Window 移动分组（保持属性）

右键菜单额外支持

函数操作说明
tabsToNewGroup(tabIds, windowId, title?) Tab(s) → New Group 创建新分组（仅右键）
tabsToNewWindow(tabIds) Tab(s) → New Window 移动到新窗口（仅右键）
groupToNewWindow(sourceGroupId) Group → New Window 移动到新窗口（仅右键）
💡 设计原则

所有移动逻辑集中在 MoveOperations 模块。拖拽只支持移动到现有目标；创建新目标（New Group/New Window）仅通过右键菜单。
