💾 会话管理

保存和恢复浏览状态

保存机制

触发方式说明
自动保存每 10 分钟自动保存一次
手动保存点击 Sessions 面板的 "💾 Save Now"
⚠️ 注意

只保留一个最新的 checkpoint，每次保存会覆盖之前的数据。

保存内容

数据说明
窗口所有窗口及自定义名称
Tab Groups分组名称、颜色、包含的标签
标签URL、标题、固定状态

恢复会话

点击顶部工具栏的 💾 Sessions 按钮，有两种恢复模式：

模式按钮说明
替换🔄 Replace关闭所有当前窗口，恢复保存的会话
追加➕ Add在新窗口中打开，保留当前窗口

📦 Archive Window - 归档单个窗口

针对完整工作环境的轻量级归档功能

使用场景

  • 某个项目窗口暂时不用，但包含完整的工作环境
  • 临时关闭窗口释放资源，保留所有 tabs 和 groups
  • 多个独立工作区需要快速切换

操作流程

步骤操作
1. 归档右键窗口标题 → "📦 Archive Window"
2. 查看打开 Sessions 面板，在 "Archived Windows" 区域查看
3. 恢复点击 ↩️ 按钮恢复窗口（自动删除归档）
4. 删除点击 🗑️ 按钮删除归档
💡 Archive vs Checkpoint
  • Checkpoint：全局快照，保存所有打开的窗口，只保留最新一个
  • Archive：单窗口归档，可以保存多个，按需恢复

导入/导出

由于 Chrome 扩展无法直接写入文件系统，提供 JSON 导入导出功能：

操作说明
📤 Export JSON下载 Checkpoint 和所有 Archived Windows 为 JSON 文件
📥 Import JSON从 JSON 文件导入会话数据和归档窗口
💡 文件导出行为
  • 首次手动保存会弹出文件保存对话框
  • 之后的手动保存和自动保存会静默覆盖同一文件

存储位置

  • 数据存储在 chrome.storage.local（浏览器内部）
  • 若需版本控制，可手动导出 JSON 保存到 repo 目录

限制

  • chrome:// 开头的系统页面不会被恢复
  • 删除扩展后，chrome.storage.local 中的数据会丢失
