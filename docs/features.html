⚡ 核心功能

侧边栏、窗口管理、搜索等基本功能

1. 侧边栏标签列表

  • 在浏览器侧边栏（Side Panel）中垂直显示所有标签页
  • 按窗口分组显示
  • 支持 Chrome 原生 Tab Groups 的显示和折叠
  • 实时更新：标签创建、关闭、移动等操作会自动反映

2. 窗口管理

功能操作
显示窗口名称默认显示 "Current Window" 或 "Window {id}"
自定义窗口名称双击窗口标题栏编辑名称
保存窗口名称按 Enter 或失焦自动保存到 chrome.storage.local
取消编辑按 Escape
折叠/展开窗口点击窗口标题栏
折叠/展开所有窗口点击工具栏的 ☰ 按钮

3. 搜索

  • 顶部搜索框支持按标题或 URL 过滤标签
  • 实时过滤，输入即搜索

4. 滚动同步

不同窗口打开的侧边栏，滚动位置保持同步。

💡 实现方式

滚动位置存储在 chrome.storage.local.scrollPosition，各窗口监听变化并同步。
