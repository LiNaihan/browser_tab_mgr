⚡ 核心功能

侧边栏、窗口管理、搜索等基本功能

1. 侧边栏标签列表

  • 在浏览器侧边栏（Side Panel）中垂直显示所有标签页
  • 按窗口分组显示
  • 支持 Chrome 原生 Tab Groups 的显示和折叠
  • 实时更新：标签创建、关闭、移动等操作会自动反映

2. 窗口管理

功能操作
显示窗口名称默认显示 "Current Window" 或 "Window {id}"
自定义窗口名称双击窗口标题栏编辑名称
保存窗口名称按 Enter 或失焦自动保存到 chrome.storage.local
取消编辑按 Escape
折叠/展开窗口点击窗口标题栏
折叠/展开所有窗口点击工具栏的 ☰ 按钮

3. 搜索

  • 顶部搜索框支持按标题或 URL 过滤标签
  • 实时过滤，输入即搜索

4. 滚动同步

不同窗口打开的侧边栏，滚动位置保持同步。

💡 实现方式

滚动位置存储在 chrome.storage.local.scrollPosition，各窗口监听变化并同步。

5. 重复标签去重

扫描所有窗口中的标签，按 URL 精确匹配找出重复项，并在面板中列出供用户选择关闭。

入口

入口说明
工具栏按钮Header 中的「重复标签」按钮（两个重叠窗口图标）
状态提示存在重复时按钮变为红色，tooltip 显示重复数量

面板交互

元素说明
分组列表按 URL 分组，显示完整 URL、每组标签数量
标签项显示标题、所在窗口、Active / Pinned 状态
复选框勾选表示关闭该标签；默认保留每组第一个，其余重复项已勾选
Close Selected批量关闭已勾选的标签，按钮显示待关闭数量
Cancel / 遮罩 / ✕关闭面板，不执行任何操作
💡 与窗口右键菜单的区别

窗口右键菜单中的「Close Duplicate Tabs」仅作用于当前窗口，且自动保留每个 URL 的第一个标签。全局去重面板支持跨窗口查看，并允许手动选择保留/关闭哪些标签。

规则与限制

  • 重复判定基于 URL 精确匹配（不做 trailing slash、hash 等规范化）
  • 每个 URL 组至少保留 1 个标签，不能全部勾选关闭
  • 无重复时显示「No duplicate tabs found」
