📦 实体层次结构

侧边栏中各实体的定义和关系

层级关系

侧边栏中的实体从小到大依次为：

Session（会话） └── Window（窗口） ├── Tab Group（标签组） │ └── Tab（标签） └── Tab（未分组标签）

1. Tab（标签）

描述：最小单位，代表单个网页

属性

属性说明
title页面标题
url页面地址
favIconUrl网站图标
pinned是否固定
active是否为当前激活标签

可执行操作

  • 激活（切换到该标签）
  • 关闭
  • 移动（拖拽或右键菜单）
  • 固定/取消固定
  • 加入分组/移出分组

2. Tab Group（标签组）

描述：Chrome 原生分组功能，包含多个相关标签

属性

属性说明
title分组名称
color分组颜色（9 种可选）
collapsed是否折叠

可执行操作

  • 折叠/展开
  • 重命名
  • 改变颜色
  • 解散（保留标签）
  • 关闭（删除所有标签）
  • 移动到其他窗口（保持分组）
  • 合并到其他分组

3. Window（窗口）

描述：浏览器窗口，包含多个标签和标签组

属性

属性说明
name自定义名称（存储在 chrome.storage.local）
tabCount标签数量

可执行操作

  • 重命名（双击标题）
  • 关闭（关闭该窗口及所有标签）
  • 折叠/展开显示
  • 拖拽排序（调整在侧边栏中的顺序）
💡 显示顺序

窗口顺序可拖拽调整，保存到 chrome.storage.local，刷新后保持。

4. Session（会话）

描述：所有窗口的快照，用于保存和恢复浏览状态

属性

属性说明
savedAt保存时间
windows[]窗口列表

可执行操作

  • 保存（手动/自动）
  • 恢复（替换模式/追加模式）
  • 导出为 JSON
  • 从 JSON 导入

存储位置

chrome.storage.local.currentSession
