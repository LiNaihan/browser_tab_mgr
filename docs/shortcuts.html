⌨️ 快捷键

键盘快捷键配置

默认快捷键

快捷键功能
Alt+A (Mac: Option+A)打开/关闭侧边栏
Escape关闭右键菜单
Cmd/Ctrl + Click切换标签选中状态
Shift + Click范围选择标签

自定义快捷键

点击底部 ⚙️ 设置按钮 → "🔧 Customize Shortcuts"

或直接访问：chrome://extensions/shortcuts

💡 提示

在 Chrome 扩展快捷键设置页面，可以为 "Open sidebar" 命令设置自定义快捷键。

Manifest 配置

{
  "commands": {
    "_execute_action": {
      "suggested_key": {
        "default": "Alt+A",
        "mac": "Alt+A"
      },
      "description": "Open sidebar"
    }
  }
}
💡 _execute_action

使用 _execute_action 而非自定义命令名，配合 sidePanel.setPanelBehavior({ openPanelOnActionClick: true })，Chrome 会自动处理侧边栏的开关切换。
