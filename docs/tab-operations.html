🖱️ 标签操作

单击、多选（Cmd/Shift）操作详解

单击操作

状态操作效果
无选中单击标签激活该标签并切换到对应窗口
无选中单击关闭按钮 (×)关闭该标签
无选中单击 Tab Group 标题折叠/展开该分组
有选中单击任意位置只清除选择，不触发其他操作（遮罩效果）
有选中单击关闭按钮 (×)仍可关闭该标签

多选操作

操作效果
Cmd/Ctrl + 单击切换该标签的选中状态（添加或移除）
Shift + 单击范围选择（从上次选中位置到当前位置的所有标签）
💡 设计理念

有选中状态时，普通点击相当于有一个透明遮罩，防止误操作。只有按住 Cmd/Ctrl/Shift 才能继续多选操作。

选中状态样式

选中的标签显示蓝色半透明背景：

.tab-item.selected {
  background-color: rgba(0, 120, 212, 0.3);
}
