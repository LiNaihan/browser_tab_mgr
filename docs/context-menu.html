📋 右键菜单

标签、分组、窗口的右键菜单详解

1. 单选时（选中 1 个标签）

🔄 Reload
📋 Duplicate
📌 Pin / Unpin
📦 Move to... ▶
📤 Remove from Group
Close other tabs
✕ Close tab

"Remove from Group" 仅在标签属于某分组时显示

2. 多选时（选中 2+ 个标签）

[N tabs selected]
🔄 Reload All
📌 Pin All
📦 Move to... ▶
✕ Close N tabs

3. Move to... 子菜单

悬停展开，支持两级菜单。

一级：窗口列表

🪟 WIP ▶

交互逻辑

操作效果
悬停 "Move to..."显示窗口列表
点击窗口名直接移动到该窗口（不分组）
悬停窗口名显示分组子菜单
点击分组名移动并加入该分组
鼠标离开菜单区域自动关闭子菜单

4. 右键窗口标题

[Window (N tabs)]
➕ New Tab
📦 Archive Window
💤 Discard All Tabs
🔗 Close Duplicate Tabs
🗑️ Close Window

功能说明

菜单项功能
Archive Window保存窗口完整状态（tabs/groups/名称）并关闭，可从 Sessions 面板恢复
Discard All Tabs卸载所有非活动标签释放内存，标签保留但变灰（点击自动恢复）
Close Duplicate Tabs关闭相同 URL 的重复标签，保留每个 URL 的第一个

5. 右键分组标题

主菜单

🗑️ Close Group

Group 移动逻辑

操作效果
点击窗口名移动整个 Group 到该窗口（保持分组名称和颜色）
悬停窗口名显示合并选项
点击 "New Group"移动到目标窗口，保持原分组属性
点击其他分组名合并当前 Group 的所有 tab 到目标分组

6. 菜单关闭逻辑

操作效果
点击菜单项执行操作后关闭菜单
左键点击侧边栏其他区域关闭菜单，不触发其他操作
右键点击侧边栏其他区域关闭菜单
按 Escape关闭菜单
💡 实现方式

使用透明遮罩层（.context-menu-overlay）覆盖整个侧边栏，点击遮罩关闭菜单。

多级菜单关闭

操作效果
从有子菜单项移到无子菜单项关闭子菜单
直接移出一级菜单区域关闭所有菜单
在子菜单内移动子菜单保持显示
