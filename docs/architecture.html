Chrome API 使用

API用途
chrome.tabs标签页查询、移动、关闭、分组
chrome.tabGroupsTab Groups 查询和更新
chrome.windows窗口创建、关闭、查询

chrome.storage.local存储窗口名称、会话数据、设置

后台服务 (Service Worker)

主要职责：

  • 设置侧边栏行为（openPanelOnActionClick: true）
  • 创建定时任务（每 10 分钟自动保存）
  • 处理手动保存到文件的请求
⚠️ 注意

侧边栏关闭时，其 JS 上下文会被销毁，所以定时任务必须放在 Service Worker 中使用 chrome.alarms。

Chrome API 限制

无法隐藏原生标签栏

Chrome 扩展的权限不允许隐藏或修改浏览器原生 UI（标签栏、地址栏等）。这是 Chrome 的安全设计，防止扩展伪造浏览器界面。

侧边栏无法跨窗口同步打开/关闭

chrome.sidePanel.open() API 有严格的用户手势要求：

  • 鼠标点击侧边栏内的按钮 → ✅ 被视为有效用户手势
  • 键盘快捷键（Alt+A） → ❌ 不被视为有效用户手势
  • 点击扩展图标 → Chrome 自动打开当前窗口，不触发 action.onClicked
  • Service Worker 中的事件回调 → ❌ 不被视为有效用户手势
⚠️ 结论

无法通过单一快捷键或操作同时打开/关闭所有窗口的侧边栏。每个窗口的侧边栏需要单独打开/关闭。
