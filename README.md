# Smart Tab Cleaner 🧹

Chrome 侧边栏标签管理扩展。

## 快速开始

### 1. 加载扩展

```bash
# 图标已生成，直接加载即可
```

1. 打开 `chrome://extensions/`
2. 开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择 `browser_tab_cleaner` 文件夹

### 2. 使用

- 点击扩展图标打开侧边栏
- 或右键图标 → "打开侧边面板"

## 操作指南

### 多选
- `Cmd/Ctrl + 点击` - 切换选中
- `Shift + 点击` - 范围选择
- 普通点击 - 清除选择

### 右键菜单
- 单选：常规操作 + 创建分组
- 多选：批量操作 + 创建/加入分组

### 工具栏图标
搜索框下方的工具栏按功能分组：

- **AI 整理**：✨ 整理未分组标签 · 🔄 全部重新分组 · 查找重复标签
- **视图**：定位当前标签 · 折叠/展开窗口 · 折叠分组
- **系统**：会话(保存/恢复/归档/导入导出) · 在所有窗口开关侧栏

## AI 智能整理

调用 OpenAI 兼容接口，让模型按主题/任务把标签重新组织成「窗口 → 分组」。

### 配置
在底部 ⚙️ 设置面板的「AI 整理（LLM）」中填写：

- **Base URL**（如 `https://api.openai.com/v1`）
- **API Key**
- **Model**（如 `gpt-4o-mini`）
- **System Prompt**：完全可编辑，可「恢复默认」

### 两种整理方式
- **✨ 整理未分组标签**：只处理尚未分组的标签。会把当前已有分组信息一并发给模型，**自适应**判断——命中同名分组就「并入已有」，否则新建；预览里会标出 `并入已有` 徽章。
- **🔄 全部重新分组**：把所有非固定标签(含已分组的)整体重排，做一次全新组织。

### 规则
- 应用前会弹出预览，可勾选/取消要执行的窗口或分组。
- 单个标签不会单独建组(但允许并入已有分组)。
- 固定标签始终跳过。

## 会话安全

- 后台自动保存会话；当检测到标签/窗口数量异常骤减(如系统重启、Chrome 更新后未恢复)时，**不会直接覆盖**旧会话，而是把上一份良好状态存为**保护检查点**，可在会话面板里恢复。
- 通过窗口指纹(标签域名集合)注册表，在浏览器重启后**自动找回窗口名**。
